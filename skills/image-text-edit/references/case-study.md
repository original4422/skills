# 来源案例：iPad App Store 截图的三处文字编辑

用户要求把订阅名称改为“ChatGPT Pro 200”，将两处日期改成“2026年11月24日”，保留原时间及其余内容。

首次使用 image-gen 编辑整张截图，目标文字修改成功，但周边内容也被重绘。用户要求先讨论方法：先裁剪、编辑后贴回。进一步确认三处均为可复现白底，因此改为确定性渲染与局部合成。

最终流程：

1. 用最初的 1620×2160 原图为底图，而不是生成图或缩小后的裁剪示意图。
2. 查询 Apple 字体资料，使用 macOS 上的 CoreText 和系统字体试排。
3. 原标题“ChatGPT Plus”用 17 pt、semibold、@2x、对应基线与水平起点重绘后，比较区域像素完全一致。
4. 日期数字使用 15 pt、semibold、@2x。半像素水平位置的校准很关键。完整日期的自动中文混排间距没有同样匹配，因此没有宣称整行完全复现。
5. 保留原来的“2026年”、中文年月日和时间像素，渲染新增的月份和日期数字；根据新字宽调整后续内容的位置。标题用已匹配参数重绘。
6. 只在三处文字局部范围内合成。保存 PNG 后确认尺寸不变，三处允许区域之外不同像素数为 0。
7. 按用户要求将成品放入任务工作目录的“修改”文件夹，保留原始文件。

这些字号、颜色、坐标和比例只属于该截图，不能成为其他任务的默认常量。可复用的是校准与验证方法，而不是这组数值。

用户确认的规则：

- 仅处理纯色或容易复现背景上的局部文字与数字替换。
- 允许复用原图已有字形；不要求重绘整图或所有旧字。
- 无法完全匹配时，先展示试排与差异，由用户决定是否接受近似，不自动切换到 image-gen。

准确的表述是：**复现待改区域的旧文字以校准参数，复用原有像素，渲染新内容，再局部合成。** 旧文字校准准确与最终修改区域外不变是两个独立的验收结果。
