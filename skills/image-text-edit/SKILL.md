# 图中文字编辑

目标是修改指定内容，同时保留原图其他像素。默认使用确定性排版与局部合成；这类任务不需要 image-gen。尊重用户明确指定的工具，不能无声改换路线。

**先复现待改的旧文字来校准，再用同一参数渲染新文字；不需要重绘整张原图。** 不变的文字可直接保留；已有字形可按原始像素复用。校准匹配与最终内容正确是两项不同的检查。

## 确定编辑范围

- 以最初的原始图片为底图。示例裁剪、聊天预览和上一轮生成图不能代替原图。
- 记录准确的新旧文本、原图像素尺寸、允许修改的区域和必须保留的内容。日期旁的时间、金额、订单号等不随意联动修改。
- 在原始像素坐标中操作。矩形统一为 `[left, top, right, bottom)`，右边和下边不包含在区域内。裁剪坐标与贴回偏移必须可追溯。
- 为文字变长预留必要的空白，但不要让修改区域覆盖旁边的图标、文字或分隔线。裁剪作排版参考的区域可以较大；最终允许变化的区域应尽可能小。
- 从干净背景采样颜色并检查区域内是否一致。不能只因看上去白色就填 `#FFFFFF`。简单渐变需先验证可复现；复杂纹理或透视超出本 skill 的范围。

## 校准字体与排版

优先读取 [references/typography.md](references/typography.md)。Apple 平台文字可使用 [scripts/render_text.swift](scripts/render_text.swift) 调用原生 CoreText；用法见 [references/tools.md](references/tools.md)。其他平台优先使用与原图相符的字体和排版引擎，不把 macOS 作为所有图片的前提。

1. 若来源应用或操作系统已知，查询官方字体资料并检查本机可用字体。区分“平台默认字体”和“截图中已经实测匹配的字体”。不要让用户回答可以自行查到的事实。
2. 从旧文字中选择有代表性的完整词组或片段。用原始分辨率的裁剪作为目标，避免混入附近无关内容。保留原图以便随时重新提取。
3. 调整字体、逻辑字号、渲染比例、字重、颜色、基线、水平起点、字距及抗锯齿。先匹配旧文字，不能直接用新文字凭印象试排。搜索起点要包含半像素位置，避免把位置偏差错误补偿成更粗的字重。
4. 对旧文字作像素比较并查看放大对比。报告比较的具体区域、不同像素数及误差；不要只报告被大片白底稀释的平均误差。完全一致仅指实际比较过的区域。
5. 匹配后复用参数渲染新文字。新字符可能触发缺字回退、不同字宽或中英文间距，因此还需检查新字符、完整文本、基线和边缘是否被裁切。旧片段匹配不等于全字体已被证明匹配。

不变的中文、时间等可保留或按整数像素平移，避免重新栅格化。复用字形时保留原始尺寸与抗锯齿；不要拉伸、压缩或缩放字形来伪造匹配。新文本必须整体可读且间距自然。

无法完全匹配时，继续调查有证据支持的字体或排版差异。若字体不可获得、尝试已不再改善，提供最佳试排、放大对比、差异指标和已知限制，由用户决定是否接受近似；不要把近似结果当成完成品交付，不要自动改用 image-gen。此处的接受近似是需要用户决定的具体例外，不要求每次常规编辑都重新审批。

## 合成与验证

- 以原图副本为底图，仅覆盖事先明确的区域。新文字、擦除旧字的背景和被平移的字形都计入修改范围。
- 使用原尺寸局部图或二值掩码贴回。不要缩放整图、重新生成周边、使用有损 JPEG 保存，或通过全图颜色转换来实现局部修改。
- 用 [scripts/image_patch.py](scripts/image_patch.py) 的 `apply` 合成；它拒绝尺寸不符、越界和半透明编辑掩码，并检查允许区域以外是否有像素变化。工具接口见 [references/tools.md](references/tools.md)。若采用其他实现，保留同样的验证。
- 保存 PNG 后重新打开并验证：尺寸不变；允许区域外不同像素数为 **0**；透明度保持；指定文字准确；金额、标点、时间和其他非目标内容保持一致；无裁字、接缝或背景色块。
- 分别报告“旧文字校准是否完全一致”和“最终图修改区域外是否完全一致”。两者不能混用。内容准确性、字形一致性还要视觉检查，像素差异指标不能代替它们。

## 保存与交付

输出位置优先采用用户指定的位置和本次任务已确认的约定。否则放在原图对应工作目录的“修改”文件夹；若附件仅存在临时目录，使用当前任务工作目录下的“修改”，不要把临时附件目录当成用户的输出目录。原图不覆盖；已有不同内容的同名成品采用版本后缀。

简短说明修改了什么、匹配程度、修改范围外的验证结果，并提供成品路径。放大对比可作为辅助交付，不必把原始像素文件、候选字体和调试图全部放进“修改”。

本 skill 的来源案例与适用边界见 [references/case-study.md](references/case-study.md)；只在需要理解本次经验或排查类似字体问题时阅读。
